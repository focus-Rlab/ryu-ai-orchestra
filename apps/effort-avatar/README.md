# AURA（仮称）

毎日の努力を、能力と3D分身のオーラへ変換するスマートフォン優先のWebアプリです。Issue #15で承認されたV1 Week 3の小規模アプリとして実装しています。

## ローカル起動

```bash
npm install
npm run dev
```

## 検証

```bash
npm test
npm run build
```

記録はブラウザの`localStorage`だけに保存し、サーバー・外部送信・課金サービスは使用しません。

## 成長ルール（調整可能な初期値）

- 達成1回: 20経験値
- 実施時間: 1分あたり0.5経験値、1日120分まで
- 100経験値ごとに1レベル上昇
- 2日連続未達から、未達1日につき5経験値の緩やかな低下
- 直近の連続未達は、能力値より強くオーラの光量へ反映
- 2能力以上がレベル5に達すると複合オーラ
- レベル10ごとに小変化、25・50・100で希少演出

これらの数値は隆之介が方針を承認した後に、実装者が安全で変更しやすい初期値として置いたものです。すべて`src/progression.ts`へ集約しています。
