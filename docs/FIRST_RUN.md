# 初回実行ガイド

1. AIへこのリポジトリを読ませる。
2. `AGENTS.md` と `agents/meta-agent-builder/` を優先して読むよう指示する。
3. `templates/AGENT_REQUEST.md` を埋める。
4. Meta Agent Builderに新規エージェント案を作らせる。
5. `EVALUATION.md` で自己評価させる。
6. 隆之介が承認したものだけ追加する。
7. 実運用後に振り返りを行う。

## 初回プロンプト例

このリポジトリの `AGENTS.md` と `agents/meta-agent-builder/` を読み、Meta Agent Builderとして動作してください。新しいエージェントをすぐ作る前に、既存エージェントやSkillで代替できないか判定してください。出力は日本語で、重要な前提と承認が必要な箇所を明示してください。
