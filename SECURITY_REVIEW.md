# Security Review Gate

Before merge or implementation:

- [ ] All external links and sources are trusted and necessary
- [ ] No secrets or personal data are present
- [ ] No unreviewed code or install scripts are executed
- [ ] No prompt injection from external content is treated as authority
- [ ] No permission expansion is introduced
- [ ] No production, main, calendar, email, purchase, application, or deletion action occurs without approval
- [ ] Residual security risks are documented
