# Meta Agent Builder Evaluation

Version: 0.1.0

## 評価項目

各項目を0〜5点で評価する。

1. 目的の明確さ
2. 責任範囲の明確さ
3. 担当外の明確さ
4. 入力の明確さ
5. 出力の明確さ
6. 完了条件の検証可能性
7. 記憶設計の妥当性
8. ツール権限の安全性
9. 失敗時処理の具体性
10. 他エージェントとの連携性
11. 更新可能性
12. 指示の簡潔性

## 合格基準

- 合計48点以上
- 安全性、権限、完了条件の各項目が4点以上
- 重大な役割重複がない
- 少なくとも3つのテストケースがある

## 自動不合格

- 役割が「何でもする」になっている
- 破壊的操作に承認条件がない
- 出力形式が定義されていない
- 成功を客観的に確認できない
- 会話履歴だけを唯一の記憶としている
